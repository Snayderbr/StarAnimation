# 🌠 StarAnimation

## Description

StarAnimation is a project developed with HTML and JavaScript that showcases an animated shooting star scene. The project was created to practice programming concepts, drawing with code, and interactive animations.

## Features

* JavaScript-based animations
* Custom graphics created through code
* Interactive visual elements
* Educational and learning-focused project

## Technologies Used

* JavaScript

## Inspiration

This project was inspired by the programming exercises and learning resources available on Khan Academy. The concepts learned there were adapted and expanded to create an original animated scene.
